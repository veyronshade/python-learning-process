## Current Mini-Projects

### IPv4 Octet Validator
A beginner Python program that checks whether four integers can form a syntactically valid IPv4 address by validating each octet against the 0–255 range.

[Open the IPv4 Octet Validator](mini-projects/ipv4_octet_validator/README.md)

**Why it matters:** this was built while reinforcing IPv4 addressing, so it connects Python control-flow practice to the networking concepts I was studying at the same time.
