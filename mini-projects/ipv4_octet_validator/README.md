## 🌐✅ IPv4 Octet Validator

A beginner Python program that checks whether four integers can form a
syntactically valid IPv4 address. Each octet must be between 0 and 255.

### 👨‍💻 Concepts Practised

- User input
- Integer conversion
- Variables
- F-strings
- Conditional statements
- Comparison and logical operators

### 🚀 How to Run

```bash
python ipv4_octet_validator.py
```
